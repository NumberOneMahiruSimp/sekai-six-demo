# Emu Otori theme artwork

All three images are real official character artwork. They were downloaded
unchanged from SEGA's official Project SEKAI character site on 2026-09-22.
The profile identifies the character as **OTORI EMU / 鳳えむ**, a member of
Wonderlands × Showtime. These are not generated images.

Identity and source page:
- https://pjsekai.sega.jp/character/unite04/emu/index.html
- English character identification: https://colorfulstage.com/characters/wonderlands-showtime/emu/
