# Results illustrations and reaction stamps

These are unchanged official Project SEKAI game assets, retrieved on 2026-09-24
from the community-operated Sekai Viewer asset mirror (storage.sekai.best).
The mirror is not an official SEGA website. No artwork was generated or redrawn.

Card names, character identities, and English stamp text were matched against
https://github.com/Sekai-World/sekai-master-db-en-diff (cards.json and stamps.json).
Illustrations use the trained card artwork. The exact source URL and SHA-256 of
every file are recorded in [manifest.json](manifest.json).
